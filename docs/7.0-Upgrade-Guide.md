# Updating to 7.0

## Breaking Changes

### MinIO / Custom S3 Endpoint Configuration on macOS

When using MinIO or other S3-compatible storage services with a custom
endpoint, `AwsS3ObjectStorage` now uses `AuthenticationRegion` instead of
`RegionEndpoint` to avoid AWS SDK DNS resolution conflicts on macOS. This
should only affect you if you were relying on the previous `RegionEndpoint`
behavior for a custom endpoint; standard AWS S3 usage (no custom endpoint) is
unaffected.

### `DiskObjectStorage.RenameAsync` Overwrites an Existing Destination

Previously, renaming to a path that already existed threw an `IOException`.
It now deletes the existing destination first, matching the documented
behavior of the other providers. This should only affect you if you were
relying on that exception to detect an existing destination.

## New Features

### Azure File Storage Provider

A new `Centeva.ObjectStorage.Azure.File` package adds an `AzureFileStorage`
provider for Azure Files, alongside the existing `Centeva.ObjectStorage.Azure.Blob`
package for Blob Storage:

```csharp
var factory = new StorageFactory().UseAzureFileStorage();

var storage = factory.CreateConnection("azure.file://share=myfiles;accountName=myaccount;accountKey=myAccountKey");
```

### `CopyAsync` and `CopyAllAsync` Extension Methods

`IObjectStorage` now has `CopyAsync` and `CopyAllAsync` extension methods for
copying a single object, or recursively copying all objects under a path,
from one storage provider to another (or within the same one):

```csharp
await source.CopyAsync(sourcePath, destination, destinationPath);
await source.CopyAllAsync(sourceFolderPath, destination, destinationFolderPath);
```

### .NET Target Consolidation

Packages now consistently target `netstandard2.0` and `net8.0` (previously
some targeted `net9.0` and the GCP package additionally targeted `net6.0`, an
inconsistency introduced by mistake). `netstandard2.0` continues to cover
consumers on any of the dropped target frameworks, so this shouldn't require
any changes on your end.
