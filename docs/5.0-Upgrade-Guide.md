# Updating to 5.0

## Breaking Changes

### `ListAsync` Takes a `ListOptions` Parameter

`IObjectStorage.ListAsync` no longer takes a `recurse` boolean. Instead it
takes a `ListOptions` struct, which also lets you request metadata for the
returned entries:

```csharp
var entries = await storage.ListAsync(path, new ListOptions { Recurse = true });
```

This should only affect you if you implement `IObjectStorage` yourself, or
call `ListAsync` with a positional or named `recurse` argument.

### `WriteAsync` Takes a `WriteOptions` Parameter

`IObjectStorage.WriteAsync` now takes an optional `WriteOptions` parameter,
inserted before `cancellationToken`, letting you set the content type and
metadata of an object as it's written:

```csharp
await storage.WriteAsync(path, contentStream, new WriteOptions("application/json", null));
```

This should only affect you if you implement `IObjectStorage` yourself, or
call `WriteAsync` with a positional `cancellationToken` argument, which will
need to be passed as a named argument instead.

### `ISignedUrlObjectStorage` Renamed to `ISupportsSignedUrls`

`ISignedUrlObjectStorage` has been renamed to `ISupportsSignedUrls`, and no
longer extends `IObjectStorage` itself. It's now a standalone capability
interface, consistent with the new `ISupportsMetadata` interface. This should
only affect you if you reference `ISignedUrlObjectStorage` directly, such as
declaring a variable of that type.

### .NET 6 Target Dropped in Favor of .NET 9

The main package, along with the AWS and Azure Blob provider packages, now
target `netstandard2.0`, `net8.0`, and `net9.0` (previously `netstandard2.0`,
`net6.0`, and `net8.0`). `netstandard2.0` continues to cover consumers on
.NET 6, so this shouldn't require any changes unless you're building directly
against the `net6.0` target.

## New Features

### Object Metadata Support

Storage providers can now expose user-defined metadata on objects. The AWS
S3 and Azure Blob providers implement the new `ISupportsMetadata` interface,
which adds an `UpdateMetadataAsync` method:

```csharp
if (storage is ISupportsMetadata metadataStorage)
{
    await metadataStorage.UpdateMetadataAsync(path, new UpdateStorageEntryRequest
    {
        Metadata = new Dictionary<string, string> { ["key"] = "value" }
    });
}
```

Metadata can also be included when writing an object, via `WriteOptions`, and
retrieved via the new `StorageEntry.Metadata` property, either from
`GetAsync` or from `ListAsync` when `ListOptions.IncludeMetadata` is set to
`true`.

### Content Type on Read and Write

`WriteOptions` also lets you set the content type of an object as it's
written:

```csharp
await storage.WriteAsync(path, contentStream, new WriteOptions("application/json", null));
```

The content type is returned on the new `StorageEntry.ContentType` property
when known, from both `GetAsync` and `ListAsync`.
