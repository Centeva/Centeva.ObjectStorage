# Updating to 6.0

## Breaking Changes

### `GetDownloadUrlAsync` Takes a `SignedUrlOptions`

`ISupportsSignedUrls.GetDownloadUrlAsync` no longer accepts a
`lifetimeInSeconds` parameter. It now takes an optional `SignedUrlOptions`:

```csharp
var url = await storage.GetDownloadUrlAsync(path, new SignedUrlOptions
{
    Duration = TimeSpan.FromMinutes(30)
});
```

Omitting the `options` argument produces the same default one-day expiration
as before. Replace any call passing an `int` lifetime with a `SignedUrlOptions`
setting `Duration` to the equivalent `TimeSpan`.

### AWS SDK Updated to Version 4

The `Centeva.ObjectStorage.AWS` package now depends on `AWSSDK.S3` version 4
instead of version 3. This is a significant version bump for the underlying
SDK with its own breaking changes (see the
[AWS SDK for .NET v4 migration guide](https://docs.aws.amazon.com/sdk-for-net/v4/developer-guide/net-dg-v4.html)).
`AwsS3ObjectStorage` has been updated accordingly and its public behavior is
unchanged. This should only affect you if your code also references
`AWSSDK.S3` types directly.

## New Features

### Content-Disposition on Signed URLs

`SignedUrlOptions` now has a `ContentDisposition` property, letting you
override the `Content-Disposition` header returned when a signed URL is used
to download the object, independent of any value set when the object was
written:

```csharp
var url = await storage.GetDownloadUrlAsync(path, new SignedUrlOptions
{
    ContentDisposition = new ContentDisposition { FileName = "report.pdf" }
});
```

This is supported across the AWS, Azure Blob, and Google Cloud Storage
providers.
